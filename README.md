# 📚 Paper Agent —— 文献调研 Agent

基于大模型 + 工具调用的自主文献调研助手：输入研究主题，自动搜索真实论文、整理结构化综述，并保存为 Markdown 报告。

> 本项目为学习项目，从零手写 Agent 循环，不依赖 LangChain/LangGraph 等框架，便于理解 Agent 的本质工作原理。

## ✨ 功能

- 🔍 **多源论文搜索**：arXiv / Semantic Scholar / Crossref 三源自动故障转移
- 🧠 **自主迭代决策**：模型自己决定搜什么关键词、搜几轮、何时收敛
- 📝 **自动报告生成**：综述自动保存为 Markdown 文件（`reports/` 目录）
- 🛡️ **防幻觉约束**：无搜索结果时拒绝编造，明确说明依据来源
- 💬 **多轮对话**：可追问/换方向，Agent 基于上下文增量工作

## 🏗️ 架构

```
用户主题
   │
   ▼
┌─────────────────────────────────────┐
│  Agent 主循环（max_rounds 兜底）       │
│    模型决策 → 调用工具 → 结果反馈 → 再决策 │
└─────────────────────────────────────┘
   │
   ├── 🔧 search_papers（故障转移：arXiv → S2 → Crossref）
   └── 🔧 save_report（综述落盘）
```

## 🚀 快速开始

```bash
git clone https://github.com/你的用户名/paper_agent.git
cd paper_agent
pip install -r requirements.txt

# 配置 API key
cp .env.example .env   # 然后编辑 .env 填入你的 DEEPSEEK_API_KEY

python main.py
```

## 🧩 核心设计

| 设计 | 说明 |
|---|---|
| Agent 闭环 | 模型决策 → 工具执行 → 结果反馈 → 再决策，直到收敛（不再调工具） |
| 并行工具调用 | 单轮可并行发起多个搜索请求，降低总时延 |
| 故障转移 | 多数据源按序尝试，任一成功即返回，对模型透明 |
| 优雅降级 | 工具失败时返回结构化错误而非抛异常，模型据此调整策略 |
| 重试退避 | 429 限流时指数退避重试，遵守上游服务速率礼仪 |
| 保险丝 | `max_rounds` 兜底，防止模型陷入搜索死循环导致 API 费用失控 |
| 记忆管理 | messages 列表跨轮持久化，追问时不重复已完成的工作 |
| 缓存 | 查询结果本地落盘，重复查询零 API 成本 |

## 🛠️ 技术栈

Python 3.10+ · DeepSeek API（OpenAI 兼容协议）· 标准库（urllib/ssl/xml）· python-dotenv

## 🗺️ 版本演进

- **v1**：手写最小 Agent 循环 + DuckDuckGo 搜索 —— 理解 Agent 本质
- **v2**：切换 arXiv API，遭遇并解决 SSL 证书、429 限流问题
- **v3**：多数据源故障转移 + save_report 工具（多工具编排）
- **v4**：多轮对话记忆 + 搜索缓存 + 流式输出

## ⚠️ 已知局限

- 当仅有 Crossref 源可用时（无摘要），综述细节基于题录信息推断，重要结论请核对原文链接
- 跳过 SSL 证书验证仅为学习项目妥协，生产环境应配置受信任证书链

## 📌 做这个项目的收获（面试可聊）

1. 理解 Agent ≠ 调包框架，核心是"反馈闭环 + 工具抽象"
2. 踩过真实工程坑：API 限流、证书验证、运行配置环境变量、prompt 语言漂移
3. 建立"模型是软约束、代码是硬约束"的工程思维
